• Get 3 rounds right in a row to move up a level. More rabbits appear, so the circle has more spots (up to 12), and each rabbit is shown for less time. From level 2, some of the other rabbits appear twice.
  • Get 3 rounds wrong in a row and you drop back two levels.

You start at level 1 with 5 rabbits, each shown for 1100 milliseconds. You score one point for each round you get right. The speed trend shows how long each rabbit was shown, so lower is better. Press End Game whenever you want to stop and save your progress.
