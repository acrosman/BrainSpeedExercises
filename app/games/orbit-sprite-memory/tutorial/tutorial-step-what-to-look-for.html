Before the first rabbit appears, your target is shown beside Target image, above the circle. The target changes every round, and any of these rabbits can be it:

  • Several rabbits look alike, so check the ears, the colors, and the markings.
  • Only the target appears three times. Every other rabbit appears once, or at higher levels twice.
  • Each rabbit gets its own spot, so the target never appears twice in the same place.
